# DSP 语音信号教学演示平台 v0.5 快速使用

## 当前音频

- 正式交付包内置 `audio/builtin_demo.mp3`，程序启动后将它作为“当前音频”。
- 点击“播放原音”始终播放当前音频。
- 导入音频后，当前音频切换为导入文件；录制 3 秒后，当前音频切换为现场录音。
- 点击“恢复内置音频”才会切回内置音频。
- 公共测试仓库不保存用户提供的歌曲文件；歌曲只加入本地交付包。

## 建议课堂顺序

1. 运行 `main.m`。
2. 模块 1 实验 A：保持 900 Hz、1000 Hz、0.02 s，运行正弦采样实验，应显示欠采样，理论混叠频率约 100 Hz。
3. 第一张图只把离散 `stem` 序列作为真正的采样结果。原始连续正弦用于对照；虚线“等效混叠参考”只用于解释为什么这些采样值会表现成低频，不代表采样后得到了一条连续曲线。
4. 采样点数 N 不单独输入，由采样率 `fs` 和观察时长自动确定。例如 1000 Hz、0.02 s，在包含起点和终点时显示 21 个采样点。
5. 把采样率改为 4000 Hz，再运行，应显示正常采样，FFT 峰值约为 900 Hz。
6. 模块 1 实验 B：设置降采样因子 M。M=4 表示每 4 个原始样本只保留 1 个。这里故意不先做抗混叠低通，目的是观察错误降采样造成的混叠；工程中的正规降采样应先抗混叠滤波。
7. 模块 2：点击“分析当前语音”，观察时域波形、单边幅度谱和短时频谱。
8. 模块 3：先点击“步骤 1：生成含噪语音”，试听含噪结果；再点击“步骤 2：应用滤波器”，试听滤波结果。单频干扰 + 带阻模式下，程序会把阻带自动调整到目标干扰频率附近。
9. 模块 4：依次尝试升调、降调、机器人、明亮，并播放变声结果。
10. 顶部“一键自检”可运行核心数值测试。

## 关于加噪与滤波

最基本的加性噪声模型是 `y[n] = x[n] + v[n]`。加入 1000 Hz 或 2000 Hz 单频干扰，就是在原音频谱上新增对应频率成分，不需要先改变原声音本身的频率。课堂上应依次比较“原音 → 含噪 → 滤波后”。

## 使用边界

- 语音降采样实验故意不使用抗混叠滤波。
- 简单 FIR 适合课堂演示已知频段干扰，不等同于专业语音降噪。
- “音质优化”是频谱整形，不等于降噪。
- 升调、降调当前会同时改变音调和时长。
- AI 声线克隆仍作为后续扩展，不属于本版主体依赖。
