# DSP 语音信号教学演示平台 v0.3 快速使用

## 建议课堂顺序

1. 运行 `main.m`。
2. 模块 1 实验 A：保持 900 Hz、1000 Hz、0.02 s，运行正弦采样实验，应显示欠采样，理论表观频率和 FFT 峰值约为 100 Hz。
3. 把采样率改为 4000 Hz，再运行，应显示正常采样，FFT 峰值约为 900 Hz。
4. 模块 1 实验 B：恢复 16 kHz 内置示例，抽取因子设为 4，直接抽取后应显示新采样率 4000 Hz。这里故意不做抗混叠滤波，仅用于教学。
5. 模块 2：分析时长 2 s，点击“分析当前语音”，观察时域波形、单边幅度谱和短时频谱。
6. 模块 3：默认使用 1000 Hz 单频干扰、900–1100 Hz 带阻 FIR，点击“加噪并处理”，比较处理前后频谱和干扰频点幅值。
7. 模块 4：依次尝试升调、降调、机器人、明亮，并播放变声结果。
8. 熟悉流程后，再用“录制 3 秒”或“导入音频”换成真实语音。

## 一键自检

v0.3 顶部“一键自检”会直接运行核心数值测试，不再只显示命令。通过时状态栏显示“自检通过：核心数值算法全部通过”。

完整课堂 GUI 验收脚本位于 `tests/test_user_manual_acceptance.m`，用于自动复现上述手册主流程。

## 使用边界

- 直接抽取故意不使用抗混叠滤波。
- 简单 FIR 适合课堂演示已知频段干扰，不等同于专业语音降噪。
- “音质优化”是频谱整形，不等于降噪。
- 升调、降调当前会同时改变音调和时长。
- AI 声线克隆仍作为后续扩展，不属于本版主体依赖。
